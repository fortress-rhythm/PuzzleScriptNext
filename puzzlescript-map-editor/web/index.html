PuzzleScript Map Editor

A grid editor for PuzzleScript levels, built around the one thing text editors get wrong: copying a rectangle and pasting it as a rectangle, overwriting rather than shoving rows sideways.

  • Your real sprites, drawn from the game's OBJECTS section
  • Marquee select, copy, cut and overwrite-paste, with a live ghost preview
  • Paste across levels — the clipboard is shared
  • Flood fill, rectangles, lines, eyedropper, unlimited undo
  • Resize from any edge; nothing else in your file is touched on save

Everything happens in your browser. Nothing is uploaded.
