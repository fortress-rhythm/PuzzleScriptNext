Running this locally

Download or clone the repository and double-click index.html. The editor and the map editor both work straight off disk. Three things need a local web server, because a page opened from a file cannot fetch other files: the editor's EXPORT and SHARE, and the map editor's Try the example buttons. For those: 

./runserver.sh          # macOS, Linux (uses node if present, else python3)
runserver.bat           # Windows
npm start               # the same, from the repository root

then open http://localhost:8020/. The setup page has the long version: installing the toolchain, proving the export template loaded, and where each command has to be run from.
