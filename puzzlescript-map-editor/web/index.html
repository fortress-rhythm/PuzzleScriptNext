PuzzleScript Map Editor

A grid editor for PuzzleScript levels and sprites, built around the one thing text editors get wrong: copying a rectangle and pasting it as a rectangle, overwriting rather than shoving rows sideways.

  • Your real sprites, drawn from the game's OBJECTS section, in its own palette
  • Marquee select, copy, cut and overwrite-paste, with a live ghost preview
  • Paste across levels — the clipboard is shared
  • Flood fill, rectangles, lines, eyedropper, unlimited undo
  • A Sprites workspace for the ASCII art itself, with the same tools
  • Sample any of the 24 palettes on your game without touching the file
  • Reads PuzzleScript Next: // comments, tags, Name glyph; colours

Everything happens in your browser. Nothing is uploaded.
