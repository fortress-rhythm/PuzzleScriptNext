The Level Editor

In addition to editing the levels as text files, which is good for small modifications, there's a level editor. Just click the level editor button in the toolbar and you'll switch to editor mode in-game, and see something like this.

You can left click to select tiles in the toolbar, and also to paint them in the main window. The tiles are generated from the 1-letter object types defined in the legend and elsewhere - basically anything you can put on a map is displayed on top in the level editor. (Right click, or ⌘/Ctrl+click to delete).

You can also use the number keys 1 to 0 on your keyboard to select tiles.

If you hover over a tile you will see a message showing all the objects, layer by layer. Or if you hover over the borders, a + symbol appears

Then if you left click it'll add an extra row/column to that side. If you right-click, it'll remove one.

Click the S button to save the output to your console, where you can paste it back in the level section if you want.

If you've messed with the map so that it's not in a state that can be converted faithfully into single-character glyphs, the editor will output the closest approximation it can find.

Selecting and pasting rectangles

Moving a chunk of map around is awkward in a text editor, because pasting a block of text inserts it and shoves the rest of every row sideways. The level editor treats a rectangle as a rectangle instead: a paste overwrites the region it lands on, and the map never changes size.

Hold shift and drag across the map to select a rectangle. Plain dragging still paints, so nothing about the rest of the editor changes. The selection is shown as a dashed blue box.

With a selection made:

  • ⌘/Ctrl+C copies the rectangle.
  • ⌘/Ctrl+X cuts it, leaving background behind.
  • Delete or Backspace clears it to background without copying.
  • ⌘/Ctrl+A selects the whole map.

⌘/Ctrl+V then arms a paste. Nothing is written yet — a translucent ghost of the copied tiles follows your cursor inside a dashed green box, so you can see exactly which cells are about to be overwritten. Left click to stamp it down; right click or Escape cancels.

Anything that would land outside the map is dropped rather than growing it, and the console tells you how many tiles fell off the edge. Pastes go through the normal undo, so Z puts things back.

The clipboard survives switching levels, so you can copy a room out of one level and stamp it into another.

Tips:

  • Press E while playing the game in the editor to toggle the level editor.
  • Press R to reset to the last time the editor was toggled.
  • Press ⌘/Ctrl+left click on the text of a level in the script editor or the console, to load it in game.
  • Hold shift and drag to select a rectangle, then ⌘/Ctrl+C and ⌘/Ctrl+V to copy and paste it.
